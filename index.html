What Claude does with it

  • Build: writes accessible views as it writes them, and tells you which labels it guessed.
  • Audit: checks a screen or the whole app as a VoiceOver, Voice Control, keyboard and large-text user would, and writes a ranked report.
  • Labels: tells you which App Store Accessibility Nutrition Labels you can claim, per device.
  • Copy review: finds hard-to-read text and instructions like "tap the red button", and suggests plainer wording.
  • Test: adds accessibility UI tests to your project.

Your code stays yours

When Claude runs a check, it sends the files it's checking to the server. They're written to a temporary folder, checked, and deleted straight away. We don't keep your code or log it.

Questions

Do I need the free skill if I buy Pro?

It's not required, but keep it. It handles Dynamic Type without a network call and tells Claude to use the Pro connector for everything else.

Which Claude plans does it work with?

Pro works anywhere you can add a custom connector, including the Claude app and Claude Code. The free skill works anywhere Claude supports skills.

Does it replace testing with real people?

No. It catches most problems in code and tells you what to test on a device. Testing with disabled users is still the best check there is.

Can I use it for client work?

Yes. One subscription is for one person. Use it on as many apps as you like, for yourself or your clients.
