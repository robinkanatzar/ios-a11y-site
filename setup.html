Setup

Install the free skill in a minute. If you have Pro, connect it with your API key.

Install the free Dynamic Type skill

In the Claude app

  1. Download ios-dynamic-type.zip. Don't unzip it.
  2. In Claude, open Customize, then Skills, and upload the zip file.
  3. Make sure the skill is turned on. Then ask Claude to build or review any SwiftUI or UIKit screen, and it uses the skill on its own.

In Claude Code

  1. Download and unzip the skill into your skills folder: 
    mkdir -p ~/.claude/skills
unzip ios-dynamic-type.zip -d ~/.claude/skills
    For one project only, use .claude/skills inside the project instead.
  2. Start Claude Code in your app's folder and try: Check Dynamic Type on the settings screen.

Connect iOS Accessibility Pro

You need the API key shown after checkout. It starts with a11y_. Don't have one? Start the free trial.

In the Claude app (web, desktop or mobile)

  1. Open Settings, then Connectors, and choose Add custom connector.
  2. Name it iOS Accessibility Pro and paste this URL, with your key at the end: 
    https://ios-a11y-pro.fly.dev/mcp?key=YOUR_KEY
  3. In a chat, open the tools menu and turn on iOS Accessibility Pro.
  4. Try it: Audit the onboarding screens for accessibility.

In Claude Code

  1. Add the connector once: 
    claude mcp add --transport http ios-a11y-pro https://ios-a11y-pro.fly.dev/mcp --header "Authorization: Bearer YOUR_KEY"
    Add --scope user to use it in every project.
  2. Check it's connected with claude mcp list.
  3. Try it: Which App Store Accessibility Nutrition Labels can we claim?

Keep your key private

Anyone with your key can use your subscription. Don't commit it to a repository or share it in screenshots. If it leaks, email us and we'll replace it.

If something doesn't work

  • "A valid API key is required": the key is missing, mistyped, or the subscription has ended. Copy it again from your welcome page.
  • "Daily limit reached": you've used today's 400 tool calls. The limit resets at midnight UTC.
  • Claude doesn't use the connector: check it's turned on for the chat, then ask directly, for example "Use iOS Accessibility Pro to audit this screen".
